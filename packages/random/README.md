# @rebimboca/random

Random generation utilities.

## Tools

### Generators

#### `generateRandomNumbers(options: { amount: number; min: number; max: number; unique?: boolean; listOrder?: "asc" | "desc" | "none"; numberOrder?: "asc" | "desc" | "none" }): number[]`

### Calculators

#### `pickNumbers(options: { start: number; end: number; amount: number; name?: string }): number[]`

## Installation

```bash
pnpm add @rebimboca/random
```
