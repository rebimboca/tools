# @rebimboca/shared

Shared internal utilities across packages.

## Tools

### Data

Common constants and shared datasets.

### Types

Shared type contracts.

### Errors

Standardized error classes and factories.

### Validators

Base validators reused by domain packages.

### Formatters

Base formatters reused by domain packages.

### Utils

Cross-package helper functions.

## Installation

```bash
pnpm add @rebimboca/shared
```
