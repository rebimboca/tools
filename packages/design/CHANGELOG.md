# @rebimboca/design

## 0.2.0

### Minor Changes

- c48c212: Expansão das utilidades visuais e de design:
  - Busca inteligente e case-insensitive de símbolos Unicode com normalização (`searchSymbols`).
  - Paletas de cores predefinidas para Material Design e TailwindCSS (`getMaterialPalette` e `getTailwindPalette`).
  - Manipulação programática de tons (funções rápidas `lighten` e `darken`).
  - Harmonia e combinação de cores complementares, análogas, tríades ou monocromáticas (`generateColorHarmony`).
  - Geração de código CSS para gradientes (`generateGradient`).
  - Truncagem inteligente de strings preservando palavras inteiras (`smartTruncate`).
